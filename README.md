# PTT 情緒與台股走勢

畢業專題：分析 PTT Stock 板的投資人情緒對個股股價的影響，並試著預測隔天漲跌。
預設標的是台積電（2330），換股票只要改 `config.yaml` 的 `ticker`。

要回答的核心問題不是「能不能預測股價」，而是：
**加入情緒之後，比只用量價的模型好多少？**

## 流程與設計

```
PTT 原始資料 ──> 挑出討論 2330 的文字 ──> 每則情緒分數 ──> 每日特徵 ──┬─> 04 分析（有沒有影響）
股價、除權息、大盤 ─────────────────────────────────────────────────┴─> 05 預測（能不能用）
```

**哪些文字算「在討論這檔股票」**（`src/pttsent/ptt.py`）
- 文章：標題提到代號或別名（台積電、台積、TSMC、護國神山）。
  只有內文提到的不算，實測大多是發文範本、融資融券表或順帶一提。
- 留言：所在文章的標題有提到（整串都算），或留言本身有提到。盤中閒聊串裡提到台積的留言會被抓到。
- 引述行、`[標的]` 發文範本會先清掉；留言時間早於文章或晚 30 天以上的視為時間戳可疑而排除。

**時間對齊**（`src/pttsent/calendar.py`）：13:30 收盤前的貼文算當天，收盤後、週末、假日算到下一個交易日。
第 t 天的情緒只用 t 天收盤前看得到的貼文，預測目標是 t+1 的報酬。

**每日情緒**（`src/pttsent/features.py`）
- 同一帳號當天先平均，再跨帳號平均。避免一個人洗 50 則就主導當天情緒。
- 沒有情緒訊號的日子是缺值，不是 0（中性）。模型用 `has_sent` 標記並補值。
- 另外算看多比例、情緒分歧（標準差）、關注度（發文量、異常發文量）、推噓比。

**預測與驗證**（`src/pttsent/models.py`）
- 目標：明天漲不漲（`up_next`）。
- A 組只用量價；B 組是量價加情緒。模型是 logistic regression 與梯度提升樹，另外附兩個基準：一直猜漲、今天漲就猜明天漲。
- 滾動式訓練：每 21 個交易日重訓一次，只用預測日之前的資料，**不隨機打亂**。
- **2024 年是最終測試期**，平常跑的結果都只到 2023 年底。等特徵、模型、參數全部定案後，
  才用 `--final` 跑一次。看過之後就不能再回頭調整，否則最終測試就失去意義。

**回測**（`src/pttsent/backtest.py`）：預測會漲就收盤買進或續抱，否則空手。
買進扣手續費 0.1425%，賣出扣手續費加證交稅共 0.4425%（`config.yaml` 可設券商折扣）。

## 情緒分數：三個層級

| 方法 | 怎麼跑 | 優缺點 |
|---|---|---|
| 詞典（預設） | 直接用 | 快、可解釋；分不出描述過去還是預測未來，也抓不到反串 |
| 弱標籤分類器 | `python scripts/train_classifier.py --labels weak`，再把步驟 2–5 加上 `--method classifier` | 用 `[標的]` 文作者自填的「分類：多／空」當標籤（2019–2023 共 7,462 篇，2024 留給最終測試不拿來訓練），不花錢；但標籤是文章層級，拿去判斷短留言會有落差，而且看多比看空多 5 倍 |
| LLM 標註＋分類器 | `scripts/llm_label.py`（見檔頭說明），再 `train_classifier.py --labels llm` | 標得最準、能處理反串；要付 API 費用，並注意模型可能「知道」後來的行情（提示詞已要求只看文字、且不給日期） |

弱標籤分類器在時間切分的測試集（2022/04–2023 年底）上 macro-F1 為 0.83（看空類 F1 0.70）。
詞典法在同一批文章裡只判得出 77% 的文字，方向準確率 66%。

但把弱標籤分類器套到**留言**上，93% 被判成看多，和當天報酬的相關只剩 0.03（詞典法是 0.11）。
原因是它沒學過「中性／無關」，也沒看過短留言。所以要量留言的情緒，還是得靠 LLM 標註的標籤。

## 第一輪結果（2330、詞典法、開發期 2019–2023）

- 情緒和**當天**報酬相關 0.11，和**隔天**報酬幾乎無關（-0.01）。
- Granger 檢定：「報酬 → 情緒」顯著（lag 1 的 p = 0.003），「情緒 → 報酬」不顯著（p > 0.6）。
  比較像是股價先動，大家才開心或難過。
- 迴歸控制量價後，情緒對隔天報酬的係數不顯著（p = 0.61）。
- 預測（2020–2023，965 天）：加入情緒後 AUC 沒有提升，logit 的差距是 -0.020，95% CI [-0.041, +0.002]。
- 回測：扣掉成本後，所有模型策略都大幅輸給買進持有（+87%）。每天進出的成本吃掉一切。

這不代表專題失敗。「情緒主要反映已發生的價格變動，對隔天報酬沒有增量資訊」本身就是一個可以好好論證的結論。
要改善的方向在下面。

## 可以往哪裡做

1. **改善情緒量測**：LLM 標註 1–2 千則並抽查一部分。先確認量得準，再談預測。
2. **換預測目標**：情緒和關注度通常對**波動度**、成交量的預測力比對報酬好；也可以試 5 日報酬或相對大盤的超額報酬。
3. **多檔股票**：`--ticker` 換 2317、2603 等討論熱門的股票，看結果是否一致（熱門股之間同一天的情緒有沒有差異）。
4. **加控制變數**：鉅亨新聞量、三大法人買賣超、台指期夜盤，檢查情緒是否只是新聞的回音。
5. **降低交易頻率**：例如只在情緒極端時進場，或改成週頻，才可能撐過交易成本。
