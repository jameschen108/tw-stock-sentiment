# PTT 情緒與台股走勢

畢業專題：分析 PTT Stock 板的投資人情緒對個股股價的影響，並試著預測隔天漲跌。
預設標的是台積電（2330），換股票改 `config.yaml` 的 `ticker`，或在各步驟加 `--ticker`。

**結論先講**：在台積電、長榮與鴻海、四種情緒量法（詞典、弱標籤、LLM 標籤的 TF-IDF 與 BERT）、兩種預測目標下，PTT 情緒主要是在**反應**已發生的股價，
沒有任何組合在樣本外證明能預測隔天報酬。唯一有跡象的組合經過預先登記，在 2024 最終測試中沒有重現。
另外把作者自標多空的 [標的] 文當成個股推薦做事件研究（2016–2023 共 10,705 篇、1,467 檔）：
作者在追漲，發文後的小差距來自漲跌停鎖住的延續，跟著看多文買扣成本後賠錢，2024 預先登記的檢定也沒通過。
PTT 唯一站得住的用途是預測**熱不熱**：收盤後到隔天開盤前的討論量，在夜盤、台積電 ADR、費半、新聞量之外，
能改善當天成交量的預測（樣本外 MSE 降 1–3%），2024 預先登記的檢定通過。
詳見[結果](#結果)、[[標的] 事件研究](#標的-事件研究)、[開盤前討論量與成交量](#開盤前討論量與成交量)，
以及 [PREREGISTRATION.md](PREREGISTRATION.md)、[PREREGISTRATION_TARGET.md](PREREGISTRATION_TARGET.md)、[PREREGISTRATION_VOLUME.md](PREREGISTRATION_VOLUME.md)。

要回答的核心問題不是「能不能預測股價」，而是：
**加入情緒之後，比只用量價的模型好多少？**

## 安裝與執行

```bash
pip install -r requirements.txt
python scripts/01_prepare_ptt.py      # PTT 轉 parquet（約 1 分鐘，只需一次）＋挑出目標股票的文字
python scripts/02_score_sentiment.py  # 每則文字打情緒分數
python scripts/03_build_features.py   # 彙整成每日特徵＋預測目標
python scripts/04_analyze.py          # 相關、領先落後、Granger、迴歸、事件研究
python scripts/05_predict.py          # 滾動式預測＋回測
python -m pytest                      # 測試（時間對齊、不偷看未來、成本計算）
```

步驟 2–5 都可加 `--ticker`、`--method`（`lexicon` / `classifier_weak` / `classifier_llm` / `classifier_llm_pooled` / `classifier_bert`）；
步驟 3–5 可加 `--target open_to_close` 改成預測隔天開盤到收盤，結果存在 `*_oc` 資料夾，不會蓋掉原本的。
`scripts/06_prereg_test.py` 是預先登記的最終檢定（見 [PREREGISTRATION.md](PREREGISTRATION.md)）。

LLM 標註要 Anthropic API key：在專案根目錄建 `.env`（已 gitignore），寫一行 `ANTHROPIC_API_KEY=...`。

結果在 `output/{代號}/{方法}/`，中間產物在 `data/`（兩者都不進 git）。

## 流程與設計

```
PTT 原始資料 ──> 挑出討論 2330 的文字 ──> 每則情緒分數 ──> 每日特徵 ──┬─> 04 分析（有沒有影響）
股價、除權息、大盤 ─────────────────────────────────────────────────┴─> 05 預測（能不能用）
```

**哪些文字算「在討論這檔股票」**（`src/pttsent/ptt.py`）
- 文章：標題提到代號或別名（台積電、台積、TSMC、護國神山）。
  只有內文提到的不算，實測大多是發文範本、融資融券表或順帶一提。
- 別名會撞到別家公司時，`config.yaml` 的 `exclude` 列出的詞會先從文字刪掉再比對。
  例如「長榮」會撞「長榮航」（2618），所以 2603 排除長榮航／長榮空／長榮鋼。
- 留言：所在文章的標題有提到（整串都算），或留言本身有提到。盤中閒聊串裡提到台積的留言會被抓到。
- 引述行、`[標的]` 發文範本會先清掉；留言時間早於文章或晚 30 天以上的視為時間戳可疑而排除。

**時間對齊**（`src/pttsent/calendar.py`）：13:30 收盤前的貼文算當天，收盤後、週末、假日算到下一個交易日。
第 t 天的情緒只用 t 天收盤前看得到的貼文，預測目標是 t+1 的報酬。
`--target open_to_close` 時改以 09:00 切日：第 t 列的情緒收到 t+1 開盤前為止（含盤後討論），目標是 t+1 開盤到收盤。

**報酬**（`src/pttsent/prices.py`）：除權息日用參考價還原。超過漲跌幅限制的報酬（例如 2603 在 2022-09-19 減資恢復交易）
不可能是真的，因為手邊沒有減資參考價，直接設成缺值。

**每日情緒**（`src/pttsent/features.py`）
- 同一帳號當天先平均，再跨帳號平均。避免一個人洗 50 則就主導當天情緒。
- 沒有情緒訊號的日子是缺值，不是 0（中性）。模型用 `has_sent` 標記並補值。
- 另外算看多比例、情緒分歧（標準差）、關注度（發文量、異常發文量）、推噓比。

**預測與驗證**（`src/pttsent/models.py`）
- 目標：明天漲不漲（`up_next`）。
- A 組只用量價；B 組是量價加情緒。模型是 logistic regression（C=0.01），另外附兩個基準：一直猜漲、今天漲就猜明天漲。
- 滾動式訓練：每 21 個交易日重訓一次，只用預測日之前的資料，**不隨機打亂**。
- **2024 年是最終測試期**，平常跑的結果都只到 2023 年底。等特徵、模型、參數全部定案後，
  才用 `--final` 跑一次。看過之後就不能再回頭調整，否則最終測試就失去意義。

**回測**（`src/pttsent/backtest.py`）：預測會漲就收盤買進或續抱，否則空手。
買進扣手續費 0.1425%，賣出扣手續費加證交稅共 0.4425%（`config.yaml` 可設券商折扣）。
`open_to_close` 時每個有部位的日子都是一次當沖（證交稅減半，來回約 0.435%），另外有放空當沖策略
（開盤先賣、收盤買回），包含「低情緒日隔天放空」：情緒 ≤ 過去 250 個交易日的 40 百分位，門檻只用過去資料滾動計算。

## 情緒分數：三個層級

| 方法 | 怎麼跑 | 優缺點 |
|---|---|---|
| 詞典（預設） | 直接用 | 快、可解釋；分不出描述過去還是預測未來，也抓不到反串 |
| 弱標籤分類器 | `python scripts/train_classifier.py --labels weak`，再把步驟 2–5 加上 `--method classifier_weak` | 用 `[標的]` 文作者自填的「分類：多／空」當標籤（2019–2023 共 7,462 篇，2024 留給最終測試不拿來訓練），不花錢；但標籤是文章層級，拿去判斷短留言會有落差，而且看多比看空多 5 倍 |
| LLM 標註＋分類器 | `scripts/llm_label.py`（見檔頭說明），再 `train_classifier.py --labels llm`，步驟 2–5 加上 `--method classifier_llm` | 標得最準、能分出幹話與反串；要付 API 費用（Batches API＋快取約每則 US$0.002），並注意模型可能「知道」後來的行情（提示詞已要求只看文字、且不給日期） |

弱標籤分類器在時間切分的測試集（2022/04–2023 年底）上 macro-F1 為 0.83（看空類 F1 0.70）。
詞典法在同一批文章裡只判得出 77% 的文字，方向準確率 66%。

但把弱標籤分類器套到**留言**上，93% 被判成看多，和當天報酬的相關只剩 0.03（詞典法是 0.11）。
原因是它沒學過「中性／無關」，也沒看過短留言。所以要量留言的情緒，還是得靠 LLM 標註的標籤。

**LLM 標註**（`src/pttsent/sentiment/llm_label.py`）用 Claude Opus 5.5（effort medium）標成
看多／看空／中性／無關，另外標 `sarcasm`（反諷）與 `banter`（幹話）。提示詞的重點：
- 只有看得出「作者自己」對未來的方向才標多空；描述或抱怨已發生的漲跌、嘲諷別人或時事、玩梗、炫耀損益都算無關。
- 中性限於認真討論前景但沒有方向；短短一句基本面、需求、競爭的判斷也算中性，不丟進無關。
- 文章以作者的「心得」段為準，不拿新聞內文當作者看法。

提示詞在 50 則上逐版抽查修正過：初版會把幹話硬標多空或丟進中性；effort 從 low 改 medium 後，模糊案例重跑 3 次的一致率從 3/9 提高到 6/9。
抽樣時排除 2024（最終測試期），每年、文章／留言等比例抽。

| | 2330 台積電 | 2603 長榮 |
|---|---|---|
| 標籤數（2019–2023） | 4,000 | 1,902 |
| API 費用 | US$8.28 | US$3.16 |
| 無關／看多／中性／看空 | 62% / 18% / 12% / 8% | 64% / 17% / 8% / 11% |
| 幹話比例 | 55% | 56% |
| 分類器 F1（看多／看空／中性／無關） | 0.39 / 0.25 / 0.42 / 0.80 | 0.49 / 0.26 / 0.27 / 0.77 |

小分類器（字元 n-gram TF-IDF + logistic regression）分得出幹話，但多空分得不好（看空 F1 約 0.25）：
反諷與語意字面上學不到，看空的樣本也少。

`train_classifier.py --labels llm_pooled` 把兩檔股票的 LLM 標籤合併（5,902 則）訓練一個共用的分類器（`--method classifier_llm_pooled`）。
同一時間切點、同一批測試文字下，和只用自家標籤比：2330 macro-F1 0.464 → 0.509、看空 0.245 → 0.379（bootstrap 95% CI 不含 0）；
2603 是 0.441 → 0.455，差距在雜訊範圍內。但 2330 的每日情緒和原本的相關 0.87（每天約 60 個帳號平均後，單則的誤判大多抵銷），
下游結果幾乎沒變（見[結果](#結果)的「LLM 合併」列）。

2317 另外標了 500 則，只當測試集、不拿來訓練（`config.yaml` 的 `llm.pool_tickers` 決定合併哪些股票）。
合併的分類器在上面 macro-F1 0.440（留言 0.421），和 2603 差不多。這批花了 US$3.50（每則約 US$0.007）：
小批次時 1 小時快取幾乎沒命中，每則都付了一次快取寫入（輸入價的 2 倍）。

**BERT**（`train_classifier.py --labels llm_pooled --model bert`，步驟 2–5 用 `--method classifier_bert`；
需要 torch、transformers，在 M2 上訓練約 30 分鐘、打分每秒約 300 則）：微調 `ckiplab/bert-base-chinese`，
留言把所在文章的標題當第一段輸入，長文保留開頭 64 個 token 加結尾（最長 256），epoch 用訓練集最後 10% 挑。
在上面同一個測試集（1,181 則）和合併的 TF-IDF 比：

| | macro-F1 | 看空 | 看多 | 中性 | 無關 | 留言 macro-F1 | 多空判反 |
|---|---|---|---|---|---|---|---|
| TF-IDF（合併） | 0.495 | 0.351 | 0.473 | 0.369 | 0.786 | 0.474 | 35 |
| BERT | **0.550** | 0.388 | **0.574** | 0.413 | **0.827** | **0.517** | 30 |

差距 +0.056（bootstrap 95% CI [+0.017, +0.096]），2330、2603 都有進步。第一版只取開頭 128 個 token 時沒有贏（0.472），
文章的心得段被截掉了；第二版的改法是看了第一版在測試集上的表現才決定的，所以提升可能略為樂觀，
所以另外在沒參與任何訓練與調整的 2317（500 則）上驗證：

| 2317 | macro-F1 | 看空 | 看多 | 中性 | 無關 | 留言 macro-F1 | 多空判反 |
|---|---|---|---|---|---|---|---|
| TF-IDF（合併） | 0.440 | 0.324 | 0.473 | 0.159 | 0.803 | 0.421 | 12 / 119 |
| BERT | **0.519** | 0.369 | 0.576 | 0.362 | 0.769 | 0.456 | 19 / 119 |

差距 +0.079（95% CI [+0.024, +0.139]），提升站得住。但 BERT 比較敢判方向（看空 recall 0.28 → 0.44，precision 約 0.31），
多空判反反而變多；分數是 P(看多) − P(看空)，判反的傷害最大，所以每日情緒不一定跟著變準。

訓練好的模型存在 `data/models/`：弱標籤是 `sentiment_clf_weak.joblib`，LLM 標籤每檔股票各一個 `sentiment_clf_llm_{代號}.joblib`，合併訓練的是 `sentiment_clf_llm_pooled.joblib`，BERT 是資料夾 `sentiment_bert_llm_pooled/`（訓練紀錄在裡面的 `training.json`）。
旁邊同名的 `.json` 記錄標籤來源、訓練期間、測試成績和 scikit-learn 版本。讀模型時若版本不同會警告，請重訓。

## 結果

開發期 2019–2023；cc = 收盤到收盤，oc = 隔天開盤到收盤（`--target open_to_close`）。
「AUC 差」是量價＋情緒（B）減只用量價（A）的 logit 模型，滾動式樣本外預測，括號是 bootstrap 95% CI。
「IC」是預測機率和隔天報酬的 Spearman 相關，用到漲跌幅，比只看漲跌的 AUC 檢定力高。
logit 原本用 C=0.1，三檔股票的 Brier 都比「過去上漲比例」這個常數差，等於在擬合雜訊；改成 C=0.01 後接近常數（2330 仍略差）。
梯度提升樹過擬合更嚴重（Brier 約 0.27），拿掉了。改了之後結論不變。

| 股票 × 方法 × 目標 | corr(情緒, 當天) | corr(情緒, 目標) | 迴歸情緒 p | Granger 報酬→情緒 p | AUC 差 | IC（A → B） |
|---|---|---|---|---|---|---|
| 2330 詞典 cc | 0.112 | −0.012 | 0.61 | 0.003 | −0.008 [−0.021, +0.004] | +0.006 → −0.003 |
| 2330 弱標籤 cc | 0.024 | −0.021 | 0.23 | — | −0.010 [−0.027, +0.006] | +0.006 → −0.002 |
| 2330 LLM cc | 0.132 | −0.024 | 0.19 | 0.0001 | +0.001 [−0.014, +0.014] | +0.006 → +0.008 |
| 2330 LLM 合併 cc | 0.124 | −0.025 | 0.17 | 0.0004 | −0.001 [−0.019, +0.015] | +0.006 → +0.004 |
| 2330 BERT cc | **0.194** | 0.001 | 0.88 | <0.0001 | −0.014 [−0.034, +0.006] | +0.006 → −0.013 |
| 2330 詞典 oc | — | 0.017 | 0.28 | — | −0.006 [−0.023, +0.006] | +0.019 → +0.000 |
| 2330 LLM oc | — | −0.001 | 0.65 | — | −0.005 [−0.024, +0.008] | +0.019 → −0.003 |
| 2603 詞典 cc | 0.122 | 0.021 | 0.47 | <0.0001 | −0.007 [−0.023, +0.005] | +0.047 → +0.033 |
| 2603 LLM cc | 0.082 | 0.036 | 0.066 | 0.50 | +0.002 [−0.010, +0.017] | +0.047 → +0.051 |
| 2603 詞典 oc | — | 0.045 | 0.047 | 0.30 | +0.003 [−0.012, +0.017] | +0.013 → +0.014 |
| **2603 LLM oc** | — | **0.064** | **0.028** | 0.68 | +0.003 [−0.007, +0.014] | +0.013 → +0.016 |

| 2317 LLM 合併 cc | 0.075 | −0.025 | 0.50 | 0.022 | −0.008 [−0.029, +0.011] | +0.028 → +0.026 |
| 2317 BERT cc | 0.127 | 0.024 | 0.21 | <0.0001 | +0.000 [−0.022, +0.021] | +0.028 → +0.030 |

1. **情緒是在反應股價**：情緒和當天報酬相關 0.075–0.19，詞典法與 BERT 的「報酬 → 情緒」Granger 檢定非常顯著（BERT 三檔 p ≤ 0.001）。
2. **量得越準，當天相關越高**：台積電從詞典 0.112、LLM TF-IDF 0.124–0.132 到 BERT 0.194。
   長榮的 LLM TF-IDF 情緒原本看起來不跟著股價走（報酬 → 情緒 p 0.50–0.68），當時以為是提示詞排除了「描述今天漲跌」；
   但換成 BERT 後 p = 0.001，比較可能是舊分類器每天只量到約 8 個帳號、太粗。弱標籤分類器把 9 成留言判成看多，幾乎量不到東西。
3. **開發期沒有可靠的預測力**：所有組合加入情緒後 AUC 都沒有顯著提升。回測扣成本後都輸給買進持有
   （2330 +87%、2603 +1057%，後者是 2020–2021 航運行情；2317 +39%）。
4. **唯一的跡象**：2603 LLM oc，情緒最低的兩個五分位隔天盤中平均 −47、−96 bp，其他約 0；
   「低情緒日隔天放空當沖」在開發期扣成本後 +7%。但它是從約 10 種組合中挑出來的。
5. **鴻海重複驗證**：2317 是看結果之前就選定的新樣本，只跑一種組合（LLM 合併分類器、cc、開發期），
   結果和前兩檔一致：報酬 → 情緒 Granger p 0.022、情緒 → 報酬 p 0.47，加入情緒 AUC 沒有提升。
   鴻海每天有情緒訊號的帳號中位數只有 4 個（2603 是 8 個），量得比較粗，當天相關也較低。
6. **BERT 重跑三檔**：每天有情緒訊號的帳號約多一倍（2330 59 → 97、2603 8 → 15、2317 4 → 10），當天相關三檔都上升；
   每日情緒和原本的方法只相關 0.38–0.52，是真的量到不一樣的東西。但隔天相關仍在 0 附近（0.001–0.029，都不顯著），
   加入情緒後 AUC、IC 都沒有提升。量法明顯變好，結論不變。

**最終測試（2024，預先登記）**：把上面第 4 點的假設、門檻與檢定程式先 commit，再跑一次 2024。

| 假設 | 開發期（樣本內） | 2024 | 判定 |
|---|---|---|---|
| H1 情緒迴歸係數 > 0 | +0.0084，p = 0.014 | −0.0048，p = 0.69 | 未通過 |
| H2 低情緒日隔天盤中報酬較低 | −59.6 vs −1.4 bp，p = 0.003 | −4.8 vs −21.7 bp（相反），p = 0.73 | 未通過 |
| H3 低情緒日放空當沖扣成本後賺錢 | +7.3% | −36.0% | 未通過 |

開發期的跡象在 2024 完全沒有重現，視為多重比較下的偶然。
**結論：PTT 情緒反映的是已發生的價格變動，對隔天報酬沒有可在樣本外驗證的增量資訊。**
2024 已經用掉了，之後若要再測新想法，需要新的資料（例如 2025 年以後）當最終測試。

## [標的] 事件研究

每日情緒是所有留言的平均；[標的] 文不同，作者照板規自己標明多空、附分析與進退場計畫，比較像個股推薦。
一篇文是一個事件，看發文前後該股票相對大盤的報酬。假設、樣本與檢定都在算任何報酬之前預先登記（[PREREGISTRATION_TARGET.md](PREREGISTRATION_TARGET.md)）。

```bash
python scripts/fetch_prices.py --market twse   # 證交所每日全部股票行情，2015–2025/06（約 3.5 小時）
python scripts/fetch_prices.py --market tpex   # 櫃買中心，同上，可以同時跑
python scripts/build_panel.py                  # 整理成全市場面板（含已下市、除權息與減資還原）並驗證
python scripts/07_target_events.py             # [標的] 文 -> 事件表（不算報酬）
python scripts/08_target_dev.py                # 開發期 2016–2023：主要假設、穩健性、檢定力
python scripts/09_target_explore.py            # 開發期的探索性分析（FDR 校正）
python scripts/10_target_prereg.py --final     # 預先登記的最終測試（2024-01 以後，只跑一次）
```

**資料**
- 文章：pttcc 加上共用資料夾的 pttweb（2015/04–2025/01，多了 2016–2018，也抓到被刪的文章），用文章 ID 合併。
- 股價：自己從證交所、櫃買中心下載每天全部股票的行情，存在 `data/prices/`（附網址、抓取時間、sha256），共用資料夾不寫入。
  上市和 FinMind 的 267 檔比對，61 萬個檔日收盤全部一致；報酬只有 38 筆不同，都是原本流程漏掉上櫃期間的除息。

**事件**
- 內文「分類」是多或空、對到恰好一檔普通股。人工抽查 200 篇，解析正確 198 篇，兩類錯誤都已修正。
- 發文後第一個收盤進場，和大盤一樣是收盤對收盤。

**開發期 2016–2023**：10,705 篇，看多 8,709、看空 1,996。

| 看多 − 看空（市場調整） | 差 | t |
|---|---|---|
| 發文後 5 天（H1） | +0.41% | 1.99 |
| 發文後 20 天（H2） | +0.54% | 1.44 |
| 同上，排除進場收盤鎖漲跌停的 4.7% | +0.09% / +0.28% | 0.47 / 0.77 |
| 發文前 5 天 | +0.69% | 2.81 |
| 發文當下（進場當天） | +0.89% | 9.1 |

1. **小差距來自漲跌停**：進場收盤就鎖漲停的看多文之後 5 天 +2.4%、鎖跌停的看空文 −6.5%。
   這是漲跌停延後價格反應造成的延續，而且收盤鎖住時通常買不到；排除後差距接近 0。
2. **作者在追漲**：看多、看空的股票發文前 20 天都已經漲了 4–5%，看多文發在短線漲完之後。
3. **跟著買會賠**：只買看多文，扣來回成本後 5 天 −0.83%、20 天 −1.51%。
   但和流動性、過去報酬相近的股票比，20 天只落後 −0.11%，主要是這類股票本身的特性。
4. **探索性分析沒有發現**（14 個特徵、FDR 校正後都不顯著）：作者過去準不準、推噓比、進場前留言的 BERT 情緒、
   附對帳單、被刪的文章、發文前有沒有鉅亨新聞，都和之後準不準沒關係。大盤文 656 篇，方向對錯接近隨機；
   有寫目標價與停損的 1,509 篇，60 天內先碰到停損約 50%、先碰到目標約 31%。

**最終測試 2024/01–2025/01（預先登記）**：596 篇，看空只有 57 篇，事先就知道檢定力只有約 5%。

| 假設 | 開發期 | 2024 | 判定 |
|---|---|---|---|
| H1 5 天 看多 − 看空 > 0 | +0.41%，單尾 p = 0.023 | −1.32%（相反），p = 0.89 | 未通過 |
| H2 20 天 看多 − 看空 > 0 | +0.54%，p = 0.075 | +1.44%，p = 0.24 | 未通過 |
| H3 發文前 20 天有差別 | −1.05%，雙尾 p = 0.048 | −2.46%，p = 0.27 | 沒有顯著差別 |

只買看多文扣成本後，2024 年 20 天 −1.41%，和開發期一致。

## 開盤前討論量與成交量

13:30 切日的每日發文量對隔天的量與波動沒有增量（見[可以往哪裡做](#可以往哪裡做)第 1 點），因為它大多在反應當天盤中的量價。
收盤後到隔天開盤前的討論發生在最後一筆成交之後，量價模型還沒看到。設定與探索過程都在 [PREREGISTRATION_VOLUME.md](PREREGISTRATION_VOLUME.md)。

```bash
python scripts/fetch_us.py                 # 台積電 ADR（TSM）與費半（^SOX）的日資料
python scripts/11_volume_prereg.py         # 開發期 2019–2023：參考值與檢定力
python scripts/11_volume_prereg.py --final # 最終測試 2024：預先登記 commit 後只跑一次（已跑過）
```

- 目標：T 日的 log 成交量（主要）與 log 振幅 ln(高/低)。預測時點是 T 開盤前。
- 訊號：T−1 13:30 到 T 09:00 的發文加留言數，減去前 20 天同一窗口的平均（`src/pttsent/volume.py`）。
- 基準：前 1／5／22 天的量價、星期與結算日等日曆、台指期夜盤、TSM 與費半的隔夜變動、鉅亨新聞量、前一天收在漲跌停、處置期間、除權息日。
- 滾動式 OLS，每 21 天重估；加入討論量前後用 Clark–West 檢定比較（多一個變數的模型直接比 MSE 會偏向小模型）。

開發期的探索：一開始只控制夜盤時，台積電成交量的 MSE 降 3.96%；加入 ADR 與費半後只剩 0.96%，大約 3/4 是在轉述 ADR 的隔夜變動。
長榮與鴻海不受影響。

**最終測試（2024，預先登記）**：

| 假設 | 開發期 | 2024 | 判定 |
|---|---|---|---|
| H1 三檔合併的成交量 | CW t = 5.48 | CW t = 3.76，p = 0.0001 | **通過** |
| H2 各檔成交量（Holm） | 2.40／3.92／3.33 | 台積電 1.67、長榮 2.63、鴻海 1.65 | 只有長榮通過 |
| H3 三檔合併的振幅 | CW t = 3.18 | CW t = 2.92，p = 0.002 | 通過 |

2024 年樣本外 MSE 變化：台積電 −1.26%、長榮 −2.96%、鴻海 −1.10%。長榮的討論量多 1 個標準差，當天成交量多約 10%。
再加入開盤跳空（市場對所有隔夜消息的加總）仍然顯著（CW t = 3.19），所以不只是隔夜消息大小的回音。
效果小，而且它預測的是當天會不會比較熱，不是漲跌方向，所以前面「PTT 不能預測報酬」的結論不變。
還沒控制的有長榮的運價、鴻海的蘋果與輝達、法說會與月營收公布日。

## 可以往哪裡做

1. **換預測目標**：文獻上關注度常能預測**波動度**。最早試的版本沒有增量：隔天 |報酬| 的滾動式預測在過去波動之外
   加上 13:30 切日的發文量，樣本外 MSE 變化 2330 −0.2%、2603 +0.1%、2317 +0.4%，信賴區間都包含 0（連成交量都沒有增量）。
   樣本內 2603 發文量的 t = 3.2，是 2021 航運熱潮時發文多、波動大同時發生。
   改用收盤後到開盤前的討論量後就有了，見[開盤前討論量與成交量](#開盤前討論量與成交量)。也可以試 5 日報酬或相對大盤的超額報酬。
2. **更好的分類器**：用中文預訓練模型（例如 BERT 系列）取代 TF-IDF，多空與反諷應該會分得更好。
3. **加控制變數**：鉅亨新聞量、三大法人買賣超、台指期夜盤，檢查情緒是否只是新聞的回音。
4. **降低交易頻率**：只在情緒極端時進場，或改成週頻，才可能撐過交易成本。
5. **多檔股票要改週頻或事件研究**：掃過 301 檔有股價的股票，2019–2023 每交易日討論量中位數 ≥ 20 則的只有 2330、2603、2317；
   聯電、陽明、中鋼、友達只有 2021 前後夠多，其他幾乎都 ≤ 5 則。另外「統一」「南亞」「大成」「華電」這類簡稱大多撞到別的公司或一般用語。
   逐日的 panel 做不起來，要改成週頻，或以討論量暴增的日子做跨股票的事件研究。
6. **新的最終測試資料**：以上任何新方向，都要用 2025 年以後的資料做一次性的樣本外驗證。
   開盤前討論量的結果也可以用 2025 年以後的 PTT 再驗證一次（pttweb 只到 2025/01，要另外抓）。
